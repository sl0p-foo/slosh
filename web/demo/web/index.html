Keys

Everything is the leader, C-a, and then a key. Press it twice to send a literal C-a to whatever is in the pane. C-a ? shows the full sheet inside the session, built from the bindings the config actually has.

Enter
split whichever way there is more room
\ -
split into columns / rows, when you mean one
h j k l
move focus (arrows work too)
o
the next pane
H J K L
move the boundary between panes
=
give every visible pane an even share
Space
turn the layout a quarter turn
z
zoom this pane to fill the tab, and back
m
minimise it into the strip along the bottom
x X
close this pane / this whole tab
c
new tab
Tab 1…9
next tab / that tab
f
find a pane by name
p
the command palette
e
edit the config, in a pane. it is re-read the moment you save
?
the cheatsheet
d q
detach, leaving it running / quit the session

Esc, or click outside, to close.

The emulator is TinyEMU / JSLinux by Fabrice Bellard, MIT licence; the kernel and BIOS are his, unmodified. The terminal is xterm.js.
