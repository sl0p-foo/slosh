slosh

a modern terminal multiplexer written in C on top of libghostty-vt.

install try it in the browser browse docs

Panes and tabs, the way your hands expect.

One chord to split — or just click, because everything drawn is a real target.

  • click the middle of a border to split toward it
  • drag the gap to move the boundary
  • drag a pane by its title to swap it
  • zoom, tab away, come back — nothing lost

Sessions outlive everything.

Detach, let the ssh connection die, come back tomorrow: every pane exactly where you left it.

  • detach mid-thought, reattach mid-thought
  • keep separate sessions for separate lives — hop between them
  • a command that died while you were away keeps its output, its exit status, and offers [re-run]

Layouts that reflow the way you expect.

The arrangement is derived from the window, never stored — so every size gets a sensible layout, and nothing drifts.

  • quarter-turn the whole layout in place
  • shrink until boxes become a tidy list
  • grow back: the exact arrangement returns

Make it yours, live.

One config file, re-read the moment you save — and C-a e opens it right there, in a pane.

  • retheme the whole session in one substitution
  • padding, gaps, titles — every knob, applied as you watch
  • compact true: a different school of borders entirely

Colour passes, written as expressions.

Dim, tint, rulers, spotlights — over a pane's cells or over its frame, with strengths computed from x, y, the cursor, the clock.

  • tint a frame, rule a column, scanline the lot
  • a spotlight that follows the cursor as you type
  • :load shine — a shipped preset runs light along the frame
  • a pane rings unfocused — its border flashes

Built to be driven.

One JSON object per line over the session's socket — the same depth the keyboard gets. An agent can hold the other end.

  • split and rename panes from a script, replies and all
  • a program draws status and buttons into its own frame
  • the click comes back on that program's stdin

install

we aim to make installing `slosh` as easy as possible. we provide binaries for most popular platforms/architectures on our github. and we also provide some arch package repo's as well as a brew formula, check below! 

$ curl -fsSL https://slosh.foo/install.sh | sudo sh

Piping a URL into a root shell should make you flinch — read it first, it is short: git, zig 0.16, one static binary into /usr/local/bin, nothing else touched.

$ brew tap sl0p/slosh https://git.sl0p.foo/homebrew-slosh.git
$ brew install slosh

No Homebrew? The linux tab's installer works here too — it only needs zig 0.16 and git.

# /etc/pacman.conf
[slosh]
Server = https://slosh.foo/arch/$arch

$ sudo pacman -Sy slosh

Built, signed packages. Enroll the signing key first — the key, the fingerprint to check and the PKGBUILD are in contrib/arch, the same instructions at arch/.

$ make -f Makefile.windows   # from a mac or linux box

The same one binary: slosh.exe, Windows 10/11, x86-64 and ARM64, no runtime dependency beyond the OS. Panes are ConPTYs, sessions are AF_UNIX sockets, everything on this page works there. Cross-compiled, then copied across — the details.

$ git clone https://slosh.foo/src slosh && cd slosh
$ make vendor    # the vendored terminal core, once
$ make           # about a second
$ sudo install build/slosh /usr/local/bin/

Needs zig 0.16 and nothing else. No cmake, no autotools, no libraries. The result is one static binary.
