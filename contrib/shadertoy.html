    x y the cell, inside the pane

    cols rows the size of the pane

    curx cury the cursor (follows your mouse), cursor 0/1

    focused 0/1   t milliseconds

    since ms in the pane's current state (bell,
    dead…); here it restarts every 3s so a flash is visible

    + - * / % integer only; division by zero is 0

    < > <= >= == != && || ! give 0 or 1, so
    (x < 10) * 200 is a rule

    & | ^ ~ << >> on the 32-bit value, binding tighter
    than comparison, so x & 7 == 0 reads as it looks

    a ? b : c   min max abs clamp dist

    sin cos take degrees and answer -255..255, so
    128 + sin(t / 4) / 2 is a breathe

    dist counts a row double, because a cell is about twice as
    tall as it is wide.
